## Project
Lantrn is a Blazor InteractiveServer project, with dependency to XBerg, QDrant and OpenAI compatible endpoints.
The goal of this project is to create a easy to use semantic search application for people to upload their documents then browse.

We also have Lantrn-docs a VitePress application for our documentation.

## Database & Migrations
Never write migrations manually always use the dotnet ef commands.

## Code standard
Always use {} even on oneliners.
Keep comments to a minimum, comments are only needed when the code isnt self explanatory. Goal is to always write self explanatory code.
KISS.
